# Amazon Marketplace Business Analytics (SQL)

## Project Overview

This project demonstrates an end-to-end SQL analysis of an Amazon Marketplace sales dataset. The objective is to transform raw transactional data into meaningful business insights that support data-driven decision making.

This project is **Phase 1** of my **Amazon Marketplace Analytics Series**, where I will progressively build a complete Business Analyst portfolio using the same dataset.

---

## Business Problem

Amazon Marketplace processes thousands of customer transactions every day. Business stakeholders need reliable insights to:

- Monitor sales performance
- Understand customer purchasing behavior
- Evaluate product and brand performance
- Track operational metrics
- Support business decision-making

This project uses SQL to answer these business questions.

---

## Dataset

**Source:** Kaggle – Amazon Sales Dataset

**Database:** MySQL

### Dataset Snapshot

- 100,000 Marketplace Orders
- 20 Business Attributes
- Customer Information
- Product & Brand Details
- Geographic Data (City, State, Country)
- Payment Methods
- Order Status
- Revenue, Tax, Shipping Cost & Discounts
